## Présentation

Micro-service Express qui sert la configuration distante de l'application Cursus Actualité : paramètres modifiables sans republier l'application sur le store.

**Pourquoi ce choix.** Publier une mise à jour pour changer un prix ou une URL prend des jours. Une configuration servie à distance prend une seconde.

---

## Ce que fait le projet

- Configuration servie en JSON
- Modifiable sans nouvelle version de l’application
